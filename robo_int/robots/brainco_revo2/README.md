# 强脑 Revo2 灵巧手接入

> 硬件：强脑科技（BrainCo）Revo2 灵巧手。
> 待办第一项就是**确认 SDK 的开放程度**（Python/CAN/串口/厂商 SDK 获取方式），
> 这决定接入成本，直接影响灵巧手任务的排期。

## 接入步骤（TODO）

1. [ ] 摸底 SDK：接口形式（CAN/OpenCAN/串口/厂商库）、控制频率、
   手指自由度数与耦合、力/触觉是否可读
2. [ ] `Revo2Hand(BaseRobot)`：
   - 手指位置目标控制（send_action = 各指关节目标）
   - 状态读取（关节位置；有力传感更好——SARM2/接触任务用）
3. [ ] 与 Unitree 人形拼 `CompositeRobot`：动作/状态维度拼接、时间戳对齐
4. [ ] 灵巧手任务套件（tasks/dexterous/）：抓握姿势复现 -> 物体抓取 ->
   in-hand 旋转 -> 精细装配
5. [ ] `[revo2]` extra 落定

## 注意

- 腱绳传动的回差/迟滞比刚性关节大，动作下发频率与平滑滤波需要实测调参；
- 若力/触觉不可读，接触丰富任务改用 ee_wrench（腕部传感）或视觉代理。
